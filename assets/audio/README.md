# 음성 슬롯

앱이 소리 내어 말하는 문구는 **40개**입니다. 재생 우선순위는 이렇습니다.

```
① 앱에서 직접 녹음한 소리 (부모 메뉴 → 성우 녹음, 기기에 저장)
② 이 폴더의 음성 파일        (<키>.mp3 · .wav · .webm · .m4a)
③ 브라우저 TTS               (①②가 없을 때의 임시 대체)
```

효과음(획 성공, 도장, 팡파르 등)은 코드에서 합성하므로 파일이 필요 없습니다.

---

## 방법 0 — 소리 파일 올리기 (태블릿에서 가장 쉬움)

부모 메뉴 → 성우 녹음 → 문구 목록에서 그 줄의 **파일** 버튼 → 소리 파일을 고르면 끝입니다.
마이크 권한도, 보안 연결도 필요 없습니다. mp3·m4a·wav 모두 됩니다.

## 방법 A — 앱에서 한 문구씩 녹음 (권장)

부모 메뉴 → **성우 녹음** → **이어서 녹음하기**.
문구가 한 줄씩 크게 나오고, 녹음을 멈추면 저장 → 자동 재생 → 다음 문구로 넘어갑니다.
40개를 쭉 읽으면 10분 안쪽입니다. 녹음한 소리는 **그 즉시 아이 화면에 반영**됩니다.

마이크는 보안 연결에서만 열립니다.

| 접속 주소 | 녹음 |
|---|---|
| `http://localhost:8000` (PC) | ○ |
| `http://192.168.x.x:8000` (태블릿) | ✕ — 브라우저가 마이크를 막습니다 |
| `https://…` | ○ |

→ **PC에서 녹음 → 내보내기 → 이 폴더에 넣기** 순서로 하면 태블릿에서도 그 목소리가 납니다.

**내보내기**: 부모 메뉴 → 성우 녹음 → *내보내기* → `목소리-모음.zip`
→ 압축을 풀어 나온 `.wav` 파일을 **이 폴더에 그대로** 넣습니다(이름 바꾸지 마세요).
내보낼 때 자동으로 모노 22.05kHz로 변환하고, 앞뒤 무음을 다듬고, 음량을 고르게 맞춥니다.

## 방법 B — 한 번에 쭉 읽은 긴 파일 나누기

파일을 `source/` 에 넣고 `source/sources.json` 에 한 줄 추가하면 녹음 화면 목록에 나타납니다.
(또는 *내 파일 고르기* 로 아무 파일이나 바로 열 수 있습니다.)

```json
[
  { "file": "강규리 아나운서 목소리.mp3", "title": "강규리 아나운서 목소리" }
]
```

부모 메뉴 → 성우 녹음 → **긴 녹음 파일에서 가져오기** → 파일 선택 → 무음 기준으로 구간이 나뉩니다.
구간마다 *듣기* 로 확인하고 어떤 문구인지 고르면 그 자리에서 저장됩니다.
구간이 뭉쳐 나오면 *끊는 간격* 을 줄이고, 숨소리까지 잡히면 *민감도* 를 낮추세요.

> **녹음 요령**: 한 낱말을 읽고 **1초쯤 쉬세요.** 그래야 낱말 단위로 깔끔하게 잘립니다.
> 여러 낱말을 한 호흡에 이어 읽으면 한 구간에 뭉쳐 버립니다.

## 방법 C — 외부에서 녹음한 파일 넣기

권장: 모노, 22~44.1kHz, 앞뒤 무음 0.1초 이내.

### 캐릭터 이름 10개

이름은 부모 메뉴에서 바꿀 수 있고, 바꾸면 이 문구도 함께 바뀝니다.
그래서 **캐릭터 이름을 확정한 뒤에 녹음**하는 편이 좋습니다.

`sticker-01` ~ `sticker-10` — `assets/stickers/stickers.json` 의 `voice` 값을 따릅니다.
캐릭터 수를 바꾸면 문구 수도 함께 바뀝니다.
읽는 문구는 "특성어 + 이름"입니다 (예: `sticker-01` → "씩씩한 씩씩콩").
캐릭터를 교체하면 이름도 바뀌므로, **캐릭터를 확정한 뒤에 녹음**하세요.
