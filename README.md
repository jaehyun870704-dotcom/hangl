# 한글공부 — 한글 따라쓰기

만 4세 대상 한글 따라쓰기 앱. `한글쓰기앱_PRD_v0.3.md` 기준으로 만들었습니다.

웹앱(PWA)이며 빌드 도구·설치 패키지가 없습니다. 정적 파일 그대로 태블릿에서 실행됩니다.

## 세 단계

홈 위쪽에서 단계를 고릅니다. 단계마다 진도·스티커·친구가 따로 갑니다.

| 단계 | 무엇 | 개수 | 친구 |
|---|---|---|---|
| 1. 자모 | ㄱ ㄴ ㄷ … ㅣ 낱자 | 24 | 하늘 친구 10명 (별·구름·하트·무지개·달·꽃·눈송이·물방울·솜사탕·반딧불) |
| 2. 글자 | 가 나 다 … 히 모아쓰기 | 28 | 먹을 것 친구 10명 (딸기·사과·레몬·수박·아이스크림·컵케이크·사탕·쿠키·우유·체리) |
| 3. 낱말 | 사과 오이 가위 … 얼굴 (**두 글자만**) | 100 | 동물 친구 10명 (고양이·강아지·토끼·곰·여우·펭귄·병아리·개구리·부엉이·거북이) |

2·3단계 글자는 자모 24자를 모아 만듭니다(`src/compose.js`). 글꼴 파일이 없습니다.

**낱말은 한 글자씩 씁니다.** «사과» 면 «사» 를 화면 가득 쓰고 «과» 를 씁니다.
두 글자를 한 화면에 넣으면 네 살 손에는 글자가 너무 작아집니다.
위쪽에 낱말 전체가 뜨고 지금 쓰는 글자에 표시가 됩니다.

**1단계는 ㄱ ㄴ ㄷ 순서대로, 2·3단계는 섞어서** 냅니다.
가나다라마바사를 순서대로 내면 노래처럼 차례를 외워 버려서, 글자를 읽는 것이 아니라
순서를 외우게 됩니다. 아직 못 뗀 것 중에서 먼저 고르고, 다 뗐으면 전체에서 고릅니다.
«글자 고르기» 에서 아이가 직접 고른 것은 언제나 맨 앞에 옵니다.
(설정에서 «2·3단계 순서 섞기» 를 끄면 순서대로 갑니다.)

스티커는 **그 단계의 마지막 항목을 떼는 순간 정확히 10장이 차도록** 나눠 줍니다.
새 친구가 없는 날에는 이미 만난 친구가 나와서 축하해 줍니다.

## 이 저장소에 없는 것

소리·그림 에셋은 올리지 않습니다. **코드만 받아도 앱은 그대로 돌아갑니다.**

| 빠진 것 | 대신 쓰이는 것 | 채우는 법 |
|---|---|---|
| 음성 60개 (`assets/audio/*.wav`) | 브라우저 기계음(TTS) | 부모 메뉴 → 성우 녹음 |
| 효과음 (`assets/sfx/*`) | 코드로 합성한 소리 | 부모 메뉴 → 효과음 → 파일 |
| 캐릭터 그림 30장 (`assets/stickers/*.png`) | 코드로 그린 친구 30명 (위 표 참고) | 슬롯에 이미지 넣기 |

음성은 **실제 사람의 목소리**라 공개 저장소에 올리지 않습니다.
효과음은 내려받은 소리라 재배포 조건이 제각각이고, 캐릭터 그림은 오리지널로 교체하기 전까지
가정 내 사용 한정입니다. (PRD 6.1 / 8)

> ⚠️ **공개 금지** — 스티커 에셋이 2단계(오리지널 세트)로 교체되기 전까지는 가정 내 사용만.
> 블로그 스크린샷, 링크 공유, 스토어 업로드 모두 교체 이후입니다. (PRD 6.1)
>
> 목소리도 같습니다. 가족이 직접 녹음한 것이 아니라면 **공개 전에 사용 허락을 확인**하세요.
> 가정 내 사용과 배포는 다른 문제입니다.

## 실행

정적 서버가 필요합니다. `file://` 로 열면 모듈·서비스워커가 동작하지 않습니다.

```bash
cd hangl          # 앱 폴더
python -m http.server 8000        # 또는  npx serve -l 8000
```

- PC 확인: http://localhost:8000
- 태블릿에서 쓰기: PC와 같은 와이파이에 연결 → `http://<PC의 IP>:8000` 접속
  → 브라우저 메뉴 **홈 화면에 추가** → 전체화면 가로 모드로 실행됩니다.
- 한 번 실행하면 전부 캐시되어 **오프라인에서도 그대로 동작**합니다(차 안, 외출 시).

> 접근 제어: 공개 URL에 올리지 마세요. 로컬 실행 또는 가정 내 네트워크 한정. (PRD 8)

## 에셋 넣기

둘 다 **넣지 않아도 앱은 완전히 동작합니다.** 넣은 것부터 하나씩 교체됩니다.

| 넣는 것 | 위치 | 안 넣으면 |
|---|---|---|
| 캐릭터 그림 30장 | `01.png`~`10.png` · `s2-01.png`~`s2-10.png` · `s3-01.png`~`s3-10.png` | 코드로 그린 파스텔 캐릭터 |
| 성우 녹음 60개 | 앱에서 직접 녹음 또는 `assets/audio/*.mp3·wav` | 브라우저 TTS(한국어) |
| 효과음 | — | 코드에서 합성 (파일 불필요) |

각 폴더의 `README.md` 에 파일명 규칙과 목록이 있습니다.

## 목소리 녹음하기

> **지금 상태**: `assets/audio/` 에 음성 파일이 없고 녹음도 비어 있으면 앱은 **브라우저 기계음(TTS)** 으로 읽습니다.
> 부모 메뉴 → 성우 녹음 맨 위에 «사람 목소리 n개 · 기계음 n개» 가 항상 표시되니 여기서 확인하세요.
>
> 녹음은 **브라우저마다 따로 저장**됩니다(IndexedDB). PC에서 녹음했다면 태블릿에도 넣으려면
> *내보내기* 로 받은 wav 를 `assets/audio/` 에 넣어야 합니다.

특정한 사람의 목소리로 앱 전체를 채우려면 **그 사람이 60개 문구를 실제로 읽어야** 합니다.
샘플 음성을 바탕으로 다른 문장을 합성하는 기능은 넣지 않았습니다 —
실존 인물의 목소리를 복제하는 일이라, 본인이 직접 읽은 녹음만 씁니다.

**대본 내려받기**: 부모 메뉴 → 성우 녹음 → *대본 내려받기* → `녹음-대본.txt`
읽을 문구 60개가 번호 순으로, 발음([시옫] 등)과 녹음 요령까지 적혀 있습니다.
이 대본대로 **한 낱말 읽고 1초 쉬며** 한 번에 쭉 읽어 오면, «긴 녹음 파일에서 가져오기» 가
자동으로 잘라 순서대로 배정합니다.

**기계음을 아예 끄려면**: *녹음된 목소리만 재생* 을 켜세요. 녹음이 없는 문구는 기계음으로
읽지 않고 조용히 넘어갑니다. (아직 안 넣은 문구가 몇 개인지 옆에 표시됩니다.)

### 녹음 대신 자동 생성 (음성 복제)

60개를 읽기 어렵다면, **내 목소리 30~60초**로 전부 합성할 수 있습니다.
`tools/voice/` 에 도구가 있습니다 (Coqui XTTS-v2 + LLM 대화 CLI 포함).

```bash
cd tools/voice
pip install TTS sounddevice soundfile
python clean_audio.py 내녹음.m4a -o reference/my-voice.wav   # 잡음 정리
python make_app_voices.py --ref reference/my-voice.wav        # 60개 생성 → assets/audio/
```

레퍼런스는 **본인이 녹음했거나 사용 허락을 받은 목소리**여야 합니다. 다른 사람의 목소리를
복제해 그 사람이 하지 않은 말을 만드는 것은 사칭입니다. 특정한 목소리를 원한다면 그분께
*대본 내려받기* 로 뽑은 대본을 건네 직접 읽어 달라고 하세요.

> 자모 24개만큼은 사람이 읽은 것을 권합니다. 한 글자짜리 이름은 합성이 가장 취약하고
> 아이가 가장 많이 듣는 소리입니다. 섞어 써도 됩니다.

성우를 따로 구하지 않고 **부모 목소리를 앱 안에서 바로 녹음**할 수도 있습니다.

1. **PC에서** `http://localhost:8000` 으로 접속 (마이크는 localhost 또는 https 에서만 열립니다)
2. 부모 메뉴 → **성우 녹음** → **이어서 녹음하기**
3. 문구가 한 줄씩 크게 나옵니다. 녹음 → 멈춤 → 자동 재생 → 자동으로 다음 문구
   (스페이스바로도 시작·멈춤. 마음에 안 들면 *다시 녹음*)
4. 녹음한 소리는 **그 즉시 아이 화면에 반영**됩니다. 녹음이 없는 문구만 기계음으로 읽습니다.

읽을 문구는 60개입니다 — 자모 이름 24 + 안내 음성 6 + 캐릭터 이름 30(단계마다 10). 쭉 읽으면 15분 안쪽입니다.

2·3단계에서 읽는 «가», «사과» 같은 글자는 녹음 목록에 없습니다. 기계음으로 읽습니다
(«녹음된 목소리만 재생» 을 켜 두어도 이것만은 소리가 납니다 — 아니면 그 단계가 통째로 조용해집니다).
사람 목소리로 넣고 싶으면 `assets/audio/say-가.mp3`, `say-사과.mp3` 처럼 파일을 넣으면 됩니다.

**태블릿에도 같은 목소리를 넣으려면**: 녹음 화면의 *내보내기* → `목소리-모음.zip` 을 받아
압축을 풀고 `.wav` 파일을 `assets/audio/` 에 그대로 넣으세요. 내보낼 때 모노 22.05kHz로 변환하고
앞뒤 무음을 다듬고 음량을 고르게 맞춥니다.

> 캐릭터 이름 30개는 그림·이름을 확정한 뒤에 녹음하세요. 이름이 바뀌면 다시 녹음해야 합니다.

### 이미 녹음해 둔 긴 파일이 있다면

한 번에 쭉 읽은 파일(mp3·m4a·wav)을 앱이 잘라 줍니다.

1. 파일을 `assets/audio/source/` 에 넣고 `sources.json` 에 한 줄 추가
   (또는 녹음 화면에서 *내 파일 고르기*)
2. 부모 메뉴 → 성우 녹음 → **긴 녹음 파일에서 가져오기** → 파일 선택
3. 무음을 기준으로 구간이 나뉩니다. 구간이 너무 뭉쳐 있으면 *끊는 간격*을, 숨소리까지 잡히면 *민감도*를 조절
4. 한 구간에 여러 낱말이 뭉쳐 있으면 그 줄의 **쪼개기** 로 더 잘게 나눕니다
5. 구간마다 **듣기** → 어떤 문구인지 고르면 그 자리에서 저장됩니다
   (구간이 문구 순서대로 읽혀 있다면 **순서대로 채우기** 로 한 번에 배정한 뒤 고쳐도 됩니다)
6. 다 넣었으면 **확인하며 듣기** 로 순서대로 들어보며 엉뚱한 자리에 들어간 소리를 잡습니다

> **녹음할 때 부탁**: 한 낱말을 읽고 **1초쯤 쉬어** 주세요. 그래야 자동으로 깔끔하게 잘립니다.
> 여러 낱말을 한 호흡에 이어 읽으면 한 구간에 뭉쳐서, 일일이 다시 잘라야 합니다.

**발음**: 자모 이름은 받침이 대표음으로 나므로 녹음 화면에 발음을 함께 띄웁니다 —
시옷[시옫] · 지읒[지읃] · 치읓[치읃] · 키읔[키윽] · 티읕[티읃] · 피읖[피읍] · 히읗[히읃].

## 태블릿에서 그림·소리 넣기

태블릿에는 앱 폴더가 없습니다. 그래서 **앱 안에서 파일을 올립니다.** PC도 같은 방법으로 됩니다.

| 넣을 것 | 어디서 | 어떻게 |
|---|---|---|
| 친구 그림 (한 장씩) | 부모 메뉴 → 올리기 → **N단계 친구** | 줄마다 **그림** 버튼 → 사진첩/파일에서 고르기 |
| 친구 그림 (10장 한 번에) | 부모 메뉴 → 올리기 → **N단계 친구** | **사진 고르기** → 사진첩에서 1~10 한꺼번에 |
| 목소리 | 부모 메뉴 → 성우 녹음 → 문구 목록 | 줄마다 **파일** 버튼 → 소리 파일 고르기 |
| 효과음 | 부모 메뉴 → 성우 녹음 → 효과음 | 줄마다 **파일** 버튼 |

- 그림은 올릴 때 512px로 줄여 저장하므로 사진을 그대로 골라도 됩니다 (투명 배경 png 도 그대로 유지).
- **원래대로** 를 누르면 이름과 그림이 함께 기본값으로 돌아갑니다.
- 태블릿에서 `http://192.168...` 주소로 열면 **마이크는 브라우저가 막습니다.** 녹음은 PC(`localhost`)에서
  하고, 태블릿에는 파일로 올리거나 `assets/audio/` 에 넣은 뒤 폴더째 복사하세요.

> 앱에서 올린 그림·소리는 **그 브라우저 안에만** 저장됩니다(IndexedDB). 인터넷 사용 기록을 지우면
> 함께 사라집니다. 오래 두고 쓰려면 PC에서 `assets/stickers/`, `assets/audio/` 에 파일로 넣고
> 폴더를 통째로 태블릿에 옮기는 편이 안전합니다.

## 친구 30명 (단계마다 10명)

스티커로 모으는 친구들입니다. 단계마다 얼굴이 다릅니다 — 1단계 하늘, 2단계 먹을 것, 3단계 동물.
기본은 코드로 그린 그림이라 파일을 한 장도 안 넣어도 전부 나옵니다.

- **이름 바꾸기**: 부모 메뉴 → 올리기 → «N단계 친구». 이름을 고치면 녹음 문구도 따라 바뀌고,
  이미 녹음한 줄에는 «⚠ 이름 바뀜» 이 떠서 어디를 다시 녹음할지 바로 보입니다.
- **그림 한 번에 올리기**: 단계마다 «그림 10장 한 번에 올리기» 가 있습니다.
  사진첩에서 **1, 2, 3 … 10** 을 한꺼번에 고르면 그 번호대로 1번 친구부터 들어갑니다.
  번호가 없는 파일은 고른 차례대로 들어갑니다.
- **한 장씩 바꾸기**: 줄마다 **그림** 버튼. PC라면 `assets/stickers/` 에
  `01.png`…`10.png`(1단계) · `s2-01.png`…(2단계) · `s3-01.png`…(3단계) 로 넣어도 됩니다.
  어느 쪽이든 저장소에는 올라가지 않으니 집에서 쓰실 그림은 공개되지 않습니다.
  그림 우선순위: **올린 그림 → assets 폴더 그림 → 코드로 그린 기본 캐릭터**
- **수 늘리기·줄이기**: `stickers.json` 의 단계별 항목 수가 그대로 반영됩니다.
- 1단계 음성 키는 옛날 그대로 `sticker-01`…`sticker-10` 입니다.
  이미 녹음해 둔 것이 그대로 살아 있습니다. 2·3단계만 `sticker-s2-01` · `sticker-s3-01` 입니다.

## 효과음 바꾸기

효과음은 전부 코드로 만든 자체 사운드입니다. 파일이 없어도 소리가 납니다.
바꾸려면 부모 메뉴 → 성우 녹음 → **효과음** 에서 슬롯별로 *듣기 / 파일 / 기본* 을 고르면 됩니다.
(또는 `assets/sfx/<키>.mp3` 로 넣으면 모든 기기에 적용됩니다.)

기본 소리는 슬롯마다 여러 개 중에 고를 수 있습니다 —
다음 글자로: *반짝 아르페지오 / 요정 종소리 / 별가루 슬라이드*, 마무리: *팡파르 / 반짝 폭죽*.

| 슬롯 | 언제 |
|---|---|
| `sfx-next` | **다음 글자로 넘어갈 때** |
| `sfx-stroke` | 획을 하나 그었을 때 |
| `sfx-open` / `sfx-pop` / `sfx-stamp` / `sfx-cheer` | 상자 열기 · 캐릭터 등장 · 도장 · 마무리 |

> 특정 만화·게임의 효과음을 그대로 넣는 것은 저작물 복제입니다. 가지고 계신 파일을 슬롯에 넣어
> 가정 내에서 쓰는 것까지가 안전한 범위이고, 공개·공유하려면 직접 만든 소리이거나
> 사용이 허락된 소리여야 합니다. (스티커 에셋 1단계와 같은 규칙)

## 부모 메뉴

홈 오른쪽 위 톱니바퀴를 **한 번** 누르면 바로 «올리기» 화면이 열립니다
(주소 `#voice` 를 즐겨찾기 해 두어도 같습니다).
탭은 셋 — **진도**(단계별 현황·취약 항목·최근 14일 기록) / **올리기**(목소리·효과음·그림) /
**설정 · 백업**.

### 백업

설정 · 백업 탭에서 **지금 상태를 통째로 떠 둘 수 있습니다.** 진도·스티커·친구 이름·설정이
한 장에 담기고, 목록에서 **되돌리기** 를 누르면 그때로 돌아갑니다.

- 단계가 생기기 전에 쓰던 기록은 앱을 처음 열 때 자동으로 **«백업1»** 로 떠 두고
  1단계 자리로 옮깁니다. 옛 진도·스티커·이름·설정이 그대로 이어집니다.
- 되돌리기를 누르면 **«되돌리기 직전»** 도 자동으로 한 장 떠 둡니다. 잘못 눌러도 다시 앞으로 갑니다.
- 초기화(단계별·전체) 전에도 자동으로 한 장 떠 둡니다.
- 20장까지 보관합니다.

조절 가능한 값 (기본값은 PRD의 ★제안):

| 값 | 기본 | 의미 |
|---|---|---|
| 세션 크기 | 자동(3자 시작) | 자동이면 최근 3세션 정확도로 ±1자, 2~6자 |
| 확장 기준선 | 70% | 이 이상이면 다음 세션 +1자 |
| 유지 기준선 | 45% | 이 미만이면 -1자 |
| 글자 통과 기준 | 60% | 한 번에 통과하는 점수 |
| 점선 밴드 폭 | 12% | 선 밖으로 나가도 인정되는 폭 |
| **획 인정 기준** | **60%** | **점선을 이만큼은 따라가야 «한 획 그었다»로 셉니다** |
| 2·3단계 순서 섞기 | 켜짐 | 끄면 가 나 다 순서대로 |
| 하루 세션 상한 | 제한 없음 | |

> **글자가 저절로 채워진다면** «획 인정 기준» 을 올리세요. 반대로 아이가 열심히 그었는데
> 자꾸 인정이 안 된다면 내리세요. 0 으로 두면 살짝 스치기만 해도 획으로 셉니다.

> 첫 주는 기본값으로 두고 부모 화면의 평균 정확도를 본 뒤 조정하는 것을 권합니다. (PRD 10-1)

세션 도중 나가려면 왼쪽 위 집 버튼을 누릅니다. 옆의 되감기 버튼은 쓰던 글자를 지우고 다시 씁니다.

### 스펙을 해석해 정한 것

0. **손을 뗀다고 획이 끝난 것은 아니다** — 네 살은 한 획을 긋다 중간에 손을 뗐다 다시 짚습니다.
   손을 떼는 즉시 판정하면 그 조각이 «획 하나»로 인정되고, 인정된 획은 화면에 통째로 칠해져서
   *내가 안 그렸는데 저절로 그려졌다* 가 됩니다. 획 수만큼 스치면 글자가 저절로 끝납니다.
   두 가지로 막았습니다 — ① 손을 떼도 0.42초 기다렸다가, 그 안에 가까운 자리를 다시 짚으면
   같은 획을 이어 긋는 것으로 봅니다. ② 점선을 60% 넘게 따라가지 않은 것은 «획 하나»로 세지
   않고 지웁니다. 다만 세 번 연달아 짧으면 그냥 받아 줍니다 — 아이를 가두지 않기 위해서입니다.
   (PRD 5.3 «어떤 경우에도 완주»)
1. **커버리지 게이트** — PRD 5.2의 세 항목만 쓰면 획을 절반만 긋고도 91점이 나옵니다.
   "획을 끝까지 그었는가"를 곱셈 게이트로 넣어 절반만 그으면 통과하지 못하게 했습니다.
2. **방향 판정을 구간 단위로** — 점 하나하나를 비교하면 4세의 손떨림이 역방향으로 잡힙니다.
   경로를 16구간으로 나눠 진행 방향을 봅니다.
3. **세션 크기 변경 후 쿨다운** — "최근 3세션 평균"을 매 세션 적용하면 같은 3세션으로
   3연속 확장되어 3자→6자가 3세션 만에 일어납니다. 크기를 바꾼 뒤에는 새 3세션을 모읍니다.
4. **닫힌 획(ㅇ, ㅎ의 동그라미)은 방향에 관대** — 반대로 돌려도 0.75점이 나와 통과합니다.
   4세에게 원을 도는 방향은 좌절 요인이 되기 쉬워 그대로 두었습니다.
5. **재도전 목록의 글자는 다음 세션에 우선 배정** — 세션 크기의 1/3까지만 넣어
   새 글자 진도가 멈추지 않게 했습니다. (PRD "내일 다시 만나는 글자"의 구현)
6. **앱 갱신** — 서비스워커를 stale-while-revalidate로 두어 코드를 고치면 다음 실행 때 반영됩니다.
7. **성우 녹음을 앱 기능으로** — PRD 10-3의 "조달 방식 미정"에 대해, 외주 대신 부모가 직접
   녹음할 수 있게 만들었습니다. 녹음은 기기(IndexedDB)에 두어 즉시 반영하고, 파일로 내보내
   `assets/audio` 에 넣으면 다른 기기에도 적용됩니다. 나중에 전문 성우 파일을 넣어도
   같은 자리에 그대로 들어갑니다.

### 아직 안 한 것 (PRD 10 미결 사항)
