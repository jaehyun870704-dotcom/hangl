# 효과음 슬롯

효과음은 기본적으로 **코드로 합성**합니다. 파일이 하나도 없어도 소리가 납니다.
바꾸고 싶으면 두 가지 방법이 있습니다.

```
① 부모 메뉴 → 성우 녹음 → 효과음 → [파일] 로 고른 소리   (기기에 저장, 즉시 반영)
② 이 폴더에 <키>.mp3 · .wav 파일 넣기                    (모든 기기에 적용)
③ 아무것도 없으면 코드로 만든 기본 소리
```

| 키 | 언제 나는 소리 | 기본 소리 |
|---|---|---|
| `sfx-next` | **다음 글자로 넘어갈 때** | 반짝이며 올라가는 아르페지오 + 반짝임 꼬리 |
| `sfx-stroke` | 획을 하나 그었을 때 | 짧게 올라가는 삐릭 |
| `sfx-open` | 선물 상자를 열 때 | 바람 소리 + 올라가는 음 |
| `sfx-pop` | 캐릭터가 나올 때 | 뽕 |
| `sfx-stamp` | 도장을 찍을 때 | 쿵 (저음 + 둔탁한 노이즈) |
| `sfx-cheer` | 스티커북이 열릴 때 | 4음 팡파르 + 반짝임 |

권장: 0.3~1.0초, 모노, 너무 크지 않게(말소리를 덮지 않도록).
전환음은 **8초 이내 연출 안에서 여러 번** 나므로 짧고 가벼운 소리가 좋습니다.

## 저작권

만화·게임에서 가져온 효과음은 **가정 내 사용에 그치세요.**
앱을 공개하거나 링크를 공유하려면 직접 만든 소리이거나 사용이 허락된 소리여야 합니다.
스티커 에셋 1단계와 같은 규칙입니다. (PRD 6.1)

무료로 쓸 수 있는 소리를 찾는다면 CC0 / 퍼블릭 도메인으로 표시된 효과음 라이브러리를 쓰고,
받은 곳과 조건을 이 폴더에 적어 두세요.
